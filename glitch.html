how it works

The detected format chooses what gets mangled:

  • BMP — bit-flips pixel data after the pixel-array offset
  • PNG — mutates IDAT bytes (CRC will be wrong; browsers tolerate it)
  • JPEG — mutates scan data between SOS and EOI, never introducing a stray marker
  • GIF — mutates LZW sub-block data inside image blocks
  • other — generic mid-file mangling, header preserved

Higher levels touch more bytes and prefer harsher mutations (bit flip → rotate → random byte).
